# ІТКС · КМАН — еталонний вступний урок

Відкрийте `index.html` у браузері або розмістіть усю папку на GitHub Pages. Для GitHub Pages завантажте файли до кореня репозиторію та ввімкніть Pages (Deploy from branch).

Реалізовано: карта першого року, вступний урок, інтерактивна модель із двома параметрами, конструктор послідовності з перетягуванням та кнопками для смартфонів, відкритий мініпроєкт, локальне збереження прогресу, один друкований PDF-звіт, скидання прогресу.

PDF: кнопка відкриває системний друк, де потрібно вибрати «Зберегти як PDF». Не є прямим генератором PDF-файлу. Дані зберігаються у localStorage конкретного браузера і можуть зникнути після очищення даних. Інтернет не потрібний після завантаження файлів; PWA/service worker ще не реалізовано.

Еталон є першою ітерацією: для решти тем наразі наявна лише карта, не готові уроки. Ілюстрації не включені; графічна схема першого уроку побудована HTML/CSS. Автоматизоване тестування в реальних мобільних браузерах не виконувалося.


Оновлення: головна сторінка index.html містить повну карту двох років (модулі та теми). Перший вступний урок веде на lesson-01.html; інші теми позначені «У плані» без неіснуючих посилань.
