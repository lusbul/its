# ІТКС · дворічна навчальна програма (2026)

Усі файли попереднього сайту збережені. `program/index.html` містить навігацію за 432 окремими заняттями (216 на рік). Заняття мають спільний інтерактивний рушій `program/course.js` та дані `program/data.js`. Вихідні формулювання теоретичної і практичної частини взято з DOCX програми.

**Важливо:** це масштабна базова версія, створена за єдиним шаблоном: конструктор є навчальною умовною моделлю, а не предметним симулятором TCP, SQL, схемотехніки тощо. Для повністю спеціалізованих симуляторів кожної теми потрібна окрема розробка і педагогічне тестування. Перші наявні уроки з оригінального архіву збережено.
