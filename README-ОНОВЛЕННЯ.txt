ITS — компактна структура. 14 модулів; окрема тематична сторінка замість десятків повторюваних сесій. Теорія і практика перенесені з program/data.js, запитання з focus. Інтерактивні тренажери відтворені в спільному topic.js; старі сесійні сторінки видалені. Збережено старі вступні файли та зображення. Для публікації видаліть у репозиторії застарілі файли program/y*-t*-s*.html, інакше вони залишаться на GitHub після завантаження ZIP. Зовнішніх посилань не додано.
